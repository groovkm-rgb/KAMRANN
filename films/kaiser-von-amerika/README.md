# Der Kaiser von Amerika (cartoon-short-kit)
Vertical 1080x1920 / 30 fps cartoon short, 50.6 s. Final video: `renders/kaiser/Der-Kaiser-von-Amerika.mp4`.
Rebuild: set up a project with the cartoon-short-kit `setup.sh`, copy these files over it, add `voice.mp3`,
run `cat web/toonbase.js web/cast.js > web/toon.js`, then `node render.mjs frames 0-1517`, `python3 audio.py`, `finish.sh`.
